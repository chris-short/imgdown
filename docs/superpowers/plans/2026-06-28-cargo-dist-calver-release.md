# cargo-dist + CalVer Release Pipeline Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace imgdown's source-build Homebrew formula and ad-hoc release workflow with a cargo-dist pipeline that publishes pre-built native binaries, auto-versioned with CalVer on every push to main.

**Architecture:** A CalVer auto-tagger workflow bumps `Cargo.toml` version and pushes a git tag on every push to `main`. cargo-dist's generated `release.yml` fires on that tag, cross-compiles binaries for four platforms, uploads them to GitHub Releases, and pushes an updated formula to the `homebrew-imgdown` tap repo. No Rust toolchain required to install.

**Tech Stack:** cargo-dist, GitHub Actions, Homebrew, gh CLI

## Global Constraints

- Target platforms: aarch64-apple-darwin, x86_64-apple-darwin, x86_64-unknown-linux-gnu, aarch64-unknown-linux-gnu
- No Windows releases
- CalVer format: `0.YYYYMMDD.run_number` in Cargo.toml; `v0.YYYYMMDD.run_number` as git tag
- Homebrew tap repo: `chris-short/homebrew-imgdown`
- Secret name in imgdown repo: `HOMEBREW_TAP_GITHUB_TOKEN`
- End users must never need Rust or any build toolchain to install imgdown

### Task 4: Create CalVer auto-tagger workflow

**Files:**
- Create: `.github/workflows/tag.yml`

- [ ] **Step 1: Create the workflow file**

Create `/Users/cbshort/Projects/imgdown/.github/workflows/tag.yml` with this exact content:

```yaml
name: Auto-tag CalVer

on:
  push:
    branches: [main]

concurrency:
  group: ${{ github.workflow }}-${{ github.ref }}
  cancel-in-progress: true

jobs:
  tag:
    runs-on: ubuntu-latest
    permissions:
      contents: write
    steps:
      - uses: actions/checkout@v4
        with:
          token: ${{ secrets.GITHUB_TOKEN }}
          fetch-depth: 0

      - name: Install Rust
        uses: dtolnay/rust-toolchain@stable

      - name: Compute CalVer
        id: calver
        run: |
          VERSION="0.$(date +'%Y%m%d').${{ github.run_number }}"
          echo "version=$VERSION" >> $GITHUB_OUTPUT
          echo "tag=v$VERSION" >> $GITHUB_OUTPUT

      - name: Update Cargo.toml version
        run: |
          sed -i 's/^version = ".*"/version = "${{ steps.calver.outputs.version }}"/' Cargo.toml

      - name: Update Cargo.lock
        run: cargo update -p imgdown --precise ${{ steps.calver.outputs.version }}

      - name: Commit and tag
        run: |
          git config user.name "github-actions[bot]"
          git config user.email "github-actions[bot]@users.noreply.github.com"
          git add Cargo.toml Cargo.lock
          git commit -m "chore: bump version to ${{ steps.calver.outputs.version }} [skip ci]"
          git tag "${{ steps.calver.outputs.tag }}"
          git push origin main "${{ steps.calver.outputs.tag }}"
```

How this works:
- `[skip ci]` in the commit message prevents `rust.yml` from running on the version-bump commit
- GITHUB_TOKEN pushes do not re-trigger the same workflow (`tag.yml`), so there is no loop
- The tag push is a separate git event that triggers `release.yml` (cargo-dist)


Expected: `YAML OK`
